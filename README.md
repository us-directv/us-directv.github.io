# DIRECTV Helpdesk — GitHub Pages Website

This project uses the same blue-and-teal visual theme and layout as the LastPass reference ZIP.

## Included
- `index.html` — homepage
- `blog.html` — searchable library of 100 DIRECTV guides
- `support.html` — separate support resources page
- `articles/` — 100 individual full-length article pages
- `styles.css` — shared responsive stylesheet
- `config.js` — editable site settings, navigation, navbar buttons, categories, article URLs, SEO metadata and article content

## GitHub Pages deployment
1. Extract the ZIP.
2. Upload the contents to the root of your GitHub repository.
3. Open repository Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/ (root)`, then save.

## Customization
Edit `config.js` to manage article titles, descriptions, categories, SEO metadata, URLs and article content. The article HTML files are static pages for direct GitHub Pages loading. If you edit content in `config.js`, update the matching article HTML page as well.

## Buttons and links
Login and Support buttons appear only in the navbar. They are plain, non-linked buttons as requested. No external hyperlinks or third-party chat widget is included. Internal links between Home, Blog, Support and article pages are enabled.
